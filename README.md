🚀 Tirador Espacial - Pygame

Un juego arcade hecho con Python y Pygame donde controlas una nave espacial y debes destruir ovnis enemigos antes de que escapen o choquen contigo.

🎮 Características

* Movimiento lateral de la nave
* Disparo de balas
* Sistema de recarga
* Bombas especiales limitadas
* Contador de puntos
* Sistema de fallos
* Enemigos aleatorios
* Colisiones entre objetos


📸 Vista del juego

El jugador controla una nave espacial:

* ⬅️➡️ Moverse con las flechas
* SPACE para disparar
* B para lanzar bombas


🛠️ Tecnologías utilizadas

* Python 3
* Pygame


📦 Instalación

1. Clonar el repositorio

git clone https://github.com/tuusuario/tirador-pygame.git
cd tirador-pygame


2. Instalar dependencias

pip install pygame

3. Ejecutar el juego

python main.py

🎯 Cómo jugar

| Tecla | Acción          |
| ----- | --------------- |
| ⬅️    | Mover izquierda |
| ➡️    | Mover derecha   |
| SPACE | Disparar        |
| B     | Lanzar bomba    |


💣 Mecánicas

Balas

* Puedes disparar hasta 5 veces seguidas.
* Después entra en recarga durante 1 segundo.

Bombas

* Tienes 3 bombas especiales.
* Eliminan enemigos al impactar.

Derrota

Pierdes si:

* Un enemigo toca tu nave.
* Más de 7 enemigos escapan.
